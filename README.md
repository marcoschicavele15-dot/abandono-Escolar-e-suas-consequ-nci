# Educação para Todos — Abandono Escolar

Website educativo sobre o tema **“Abandono Escolar e suas consequências”**, preparado para publicação no GitHub Pages.

## Estrutura do projecto

```text
abandono-escolar-github/
├── index.html
├── README.md
├── .gitignore
└── assets/
    ├── style.css
    └── script.js
```

## Como visualizar

1. Extraia o ficheiro ZIP.
2. Abra `index.html` num navegador; ou use a extensão **Live Server** no Visual Studio Code.
3. Para publicar, envie todos os ficheiros e pastas para o mesmo repositório GitHub.

## Publicar com GitHub Pages

1. Crie um repositório no GitHub.
2. Carregue `index.html`, `README.md` e a pasta `assets` (com os dois ficheiros).
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Seleccione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço do website será apresentado na área GitHub Pages.

## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- JavaScript sem bibliotecas externas

A fonte tipográfica é carregada do Google Fonts quando existe ligação à Internet. O conteúdo principal e os estilos funcionam sem dependências de frameworks.
